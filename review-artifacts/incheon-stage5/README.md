# 인천 5단계: 실제 차량 렌더와 전체 비행 측정

기준은 병합된 4단계 `ea9b54febe1fd7bb4ed0d485f00e089d331cbb2e`의 수정하지 않은
별도 worktree/프로덕션 빌드입니다. 변경은 차량과 내륙 높이 질의 캐시를 포함합니다.
Intel ADL-N / ANGLE Vulkan, 1280×720 CSS, DPR 1, 정오에서 ABBA 순서로 비교했습니다.

[차량 근접](traffic-close.png) · [5초 뒤](traffic-after-5s.png) ·
[전체 원본](performance.json) · [이착륙 회귀 결과](flight-regression/results.json).

## 실제 동작

- 실제 도로 폐회로 8개 중 경사 조건을 통과한 6개, 준비 차량 40대.
- 차량은 오른쪽 차선을 따라 이동하며 품질/거리에 따라 표시합니다. 근접 검사에서
  40대 표시, 이동/정지/리셋, 원거리 0대, 비활성화 0대, 버퍼 재사용을 확인했습니다.
- 제품 일시정지와 시나리오 리셋, 공항 왕복 후 같은 객체 재사용을 별도로 확인했습니다.
- 두 PNG는 실제 GPU 렌더이며 물리와 카메라를 고정하고 차량 시간만 5초 전진했습니다.
  항공기 HUD는 이 근접 도로 검사 대상이 아닙니다. 차량은 항공기 충돌 대상이 아닙니다.
- 4단계 수용 스크립트 재사용: B737/C172 이륙 및 접근→착륙→5초 정지,
  유도로 이동, 건물 충돌 후 리셋, 로딩 실패/재시도/취소, 카메라와 390px 메뉴 통과.

## 전체 비행 FPS

셰이더 준비 30프레임은 정지 상태이며 이후 동일 시작 위치/속도에서 실제 animate와
120Hz 물리 루프를 실행하고 native RAF 구간 120개를 수집했습니다.
36개 패스의 원본 구간은 모두 보관합니다. 아래는 각 셀의 두 패스, 총 240개 구간을 합산한
평균 FPS / p95 ms입니다. `stepSimulation()` 가속 또는 단독 render 시간으로 대체하지 않았습니다.

**전체 FPS 향상은 확인되지 않았습니다.** 도시의 합산 평균은 차량 추가 후 약 4–6% 낮습니다.
기준의 도시 단일 패스도 24.8–28.9 FPS로 변하므로 평균 차이만으로 차량 비용의 정확한 비율을
단정하지 않습니다. 도시에서 차량은 한 draw call을 추가하며, 차량이 없는 먼 조종석 시점은
호출 수가 같습니다. 일부 패스의 최종 scene calls 차이는 통과 거리/화면 밖 객체의 변화도 포함합니다.
고정 시작 후 물리 위치를 덮어쓰지 않으므로 FPS에 따라 통과 거리와 물리 진행 시간은 달라집니다.
원본의 시작/종료 좌표와 counts를 함께 확인해야 합니다. 이 기기에서 60FPS 목표를 달성한 결과가 아닙니다.

## 로딩과 메모리

HTTP 캐시는 껐으며 로컬 파일 서버/OS 캐시는 따뜻할 수 있습니다. 요청부터 첫 도시 프레임까지의
두 패스는 기준 **2486–2494ms**, 변경 **2001–2106ms**였습니다. 로딩 중 최대 프레임 간격은
기준 약 2383ms, 변경 1700–1867ms이고 최대 긴 태스크는 기준 2288–2299ms,
변경 1603–1729ms입니다. **초기 로딩의 긴 정지는 아직 남습니다.**

메모리는 측정 구간 밖에서 GC 후 CDP로 읽었습니다. 페이지 이동 뒤 이전 컨텍스트가 남을 수 있어
절대 heap 총량을 비교하지 않고 각 로드 전후 증가분을 사용합니다.

- JS heap 증가: 기준 약 0.58–0.77MB, 변경 약 0.88–0.98MB.
- ArrayBuffer backing storage 증가: 기준 약 17.901MB, 변경 약 18.384MB, 차이 약 **0.483MB**.
- 새 land/coast Uint8 캐시 461,761 bytes + 차량 geometry/instance 버퍼 21,280 bytes와 대응합니다.
- 초기 도시 프레임의 geometry 수는 232→233, texture 수는 33→33입니다.
- 실제 GPU VRAM, 브라우저 전체 프로세스 메모리, 다른 GPU/물리적 휴대폰의 성능을 측정한 것은 아닙니다.

기준 CPU 진단은 별도 5초 샘플이며 FPS 표본과 분리했습니다. 높이 질의에서 반복하던
해안선 순회를 내륙 캐시로 제거했습니다. 해안 경계·작은 구멍은 원래 판정을 유지합니다.
